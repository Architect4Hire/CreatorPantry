Field

Label, hint, required, error, disabled, and every projected control type.

The control is projected, so no template binding can reach it — the field wires aria-describedby to its hint and error, and aria-required when required, after each render. Without that the * and the hint are visible and invisible at once. Optionality is the inverse and is stated once per form: marking one optional field among a dozen unmarked ones makes the rest read as required.

Diff legend

All 7 kinds by default; presentation only, no diff computation. A surface that marks up individual changes takes its glyph and wording from cpDiffGlyph() and cpDiffLabel(), so a row and the legend entry explaining it cannot drift apart.

Narrowed to the kinds one surface actually renders, so it explains nothing a reader will not meet.

Combobox

A text input that filters a list it is given, with the WAI-ARIA combobox keyboard: arrows to move, Home/End to jump, Enter to choose, Escape to close without losing what was typed. Focus never leaves the input — the active row is named by aria-activedescendant — and the number of remaining rows is announced. It fetches nothing; a consumer filtering server-side passes its own list with [filterLocally]="false".

It renders no label of its own: it composes inside cp-field, which owns the label, hint and error, and whose input styling reaches the text box inside it.

A caret marks it as a picker, and clicking the box opens the list — without both, a combobox wearing cp-field's ordinary input styling is indistinguishable from a text box, and a creator who clicks it and waits concludes the picker is missing. Focus alone does not open it: tabbing through a form would pop every list open on the way past and announce a count nobody asked for.

Restricted: text that names no unit reverts when the field is left, so the box only ever reads as the unit it stands for. Chosen: {{ unit()?.label ?? 'nothing yet' }}.

No tag by that name yet — it will be created.

Free text: what was typed stands, and the selection says whether it names something that already exists. Typed {{ tagText() || '—' }}, which is {{ tag() ? 'an existing tag' : 'new' }}.

Checkbox

A drawn control, because an unstyled <input type="checkbox"> is painted from the inherited color-scheme — in dark mode its unchecked box is a dark filled square — and arrives at 13×13 with no author focus ring. The real input is still there, focusable and announced; it is only visually replaced. Checked reads as a glyph, so the state does not depend on telling two colours apart, and the whole label is a 40px target.

Anchor nav

Ordinary navigation over a document that is all present — every item tabbable in order, no roving tabindex, deliberately not a tablist. It emits which destination was asked for; scrolling and focus stay with the consumer, which is the only side that can name the control worth focusing. With no items it renders nothing at all, so a surface with one section shows no empty shell.

Set --cp-anchor-nav-direction: column on the host — from inside a container query, typically — to stack it in a gutter. The default wrapping row is what fits above the content it names on a narrow screen and at 200% zoom.

Live status / toast

Info/success auto-dismiss after 5s and pause on hover; warning/error are persistent until dismissed.

Form section

One named part of a form: a heading, a sentence under it, the server's word on the whole part when it refuses, and the fields themselves. Every form in the app is built from these, stacked a --cp-space-8 apart, so a long form reads as named parts rather than a wall of boxes.

The section names itself from its own heading and, while a problem is showing, is described by it — so a form that moves focus here on a refusal reads the heading and then the reason. Fields projected straight into it are capped at --cp-measure-field; a field inside a component projected here is left to that component. Short fields share a line by going into a cp-field-row.
