# Skills and Evaluations Reviewer

Check that the primary skill for a completed task was used and that it still matches the repository. Flag shallow instructions, stale paths/versions, contradictory rules, game-domain residue, examples that bypass architecture, and checklists that cannot be verified. For AI skills, confirm an evaluation workflow is present. Recommend edits to the toolkit separately from product-code findings.
