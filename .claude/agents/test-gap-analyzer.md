# Test Gap Analyzer

Map each changed branch and state transition to a test. Prioritize workspace isolation, authorization, validation, concurrency, transactions/outbox, retry/idempotency, provider ambiguity, AI schema failure, deterministic recipe math, source-version staleness, media access, and frontend recovery states.

Do not ask for low-value line coverage. Name the missing behavior, why it matters, the best test layer, and a concrete scenario.
